# English B2

Матеріали для вивчення англійської до рівня B2.

| Файл | Що це |
|---|---|
| [`dialog.md`](dialog.md) | План навчання, поради та розбір результату тесту словника |
| [`english-builder.html`](english-builder.html) | Тренажер: 15 каркасів речення, 30 карток «збери речення», довідка з порядку слів |
| [`core-words.html`](core-words.html) | Тренажер: 239 найчастотніших слів, режим UA → EN уголос |
| [`vocab-test-result.png`](vocab-test-result.png) | Результат тесту словника (Preply): 1159 слів |

HTML-файли відкриваються офлайн у браузері, працюють із телефона, прогрес зберігається локально.

**Щоденний режим:** 10 хвилин «Ядро» + 10 хвилин «Каркаси».
